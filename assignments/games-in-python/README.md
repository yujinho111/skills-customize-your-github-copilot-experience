# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Practice Python fundamentals by building a classic Hangman game using strings, loops, conditionals, and user input.

## 📝 Tasks

### 🛠️ Build the Core Game

#### Description
Create a Hangman game where players guess letters to reveal a hidden word before they run out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Display the hidden word as underscores, such as `_ _ _ _ _`
- Accept single-letter guesses from the player
- Reveal correctly guessed letters in the correct positions
- Track the number of incorrect guesses remaining
- End the game when the player wins or runs out of attempts

### 🛠️ Improve the Gameplay

#### Description
Add a few user-friendly features to make the game more polished and easier to play.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted twice
- Show the letters the player has already guessed
- Display a clear win or loss message at the end of the game
- Offer the player the option to play again after each round
